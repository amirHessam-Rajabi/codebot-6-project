# پروژه کدبات ۶ — امیرحسام رجبی

یک وب‌سایت تعاملیِ تک‌صفحه‌ای که یک شبکه‌ی عصبی چندلایه (MLP) را مستقیم در مرورگر اجرا می‌کند:
رقمی بین ۰ تا ۹ روی بوم بکشید، مدل در کسری از ثانیه حدس می‌زند چه رقمی نوشته‌اید — بدون هیچ سرور، API یا اتصال اینترنتی لازم برای کارکردِ خودِ مدل.

این پروژه برداشتی زنده و تعاملی از منطق نوت‌بوک اصلی است: همان ایده‌ی «آموزش یک `MLPClassifier` روی تصاویر ۲۸×۲۸ ارقام دست‌نویس»، با این تفاوت که این‌جا برای اجرا در GitHub Pages، مدل به‌صورت آفلاین آموزش داده شده و وزن‌هایش مستقیم با جاوااسکریپت خالص اجرا می‌شود.

**برای تجربه ی این پروژه وارد https://amirhessam-rajabi.github.io/codebot-6-project/ شوید.**
## ساختار پروژه

```
project/
├── index.html          ساختار صفحه
├── style.css            تم بصری (دارک، بنفش-سیان)
├── script.js             منطق رسم، پیش‌پردازش تصویر و forward-pass شبکه‌ی عصبی
├── README.md
└── assets/
    ├── model.js          وزن‌های مدل آموزش‌دیده (لایه‌ها، وزن‌ها، بایاس‌ها)
    └── favicon.svg
```

## چطور اجرا کنم؟

فقط فایل `index.html` را با دوبار کلیک باز کنید — همه‌چیز آفلاین کار می‌کند، چون وزن‌های مدل مستقیم داخل یک فایل جاوااسکریپت (`assets/model.js`) قرار دارند و نیازی به `fetch` یا سرور نیست.

برای انتشار روی GitHub Pages:
1. محتویات همین پوشه (`project/`) را در ریشه‌ی یک ریپازیتوری قرار دهید.
2. از تنظیمات ریپازیتوری، بخش GitHub Pages را روی شاخه‌ی اصلی (branch: main, folder: /root) فعال کنید.
3. آدرس صفحه‌تان آماده می‌شود.

تنها بخشی که به اینترنت نیاز دارد، فونت «وزیرمتن» است که از Google Fonts بارگذاری می‌شود؛ اگر اینترنت نباشد، صفحه با فونت پیش‌فرض سیستم نمایش داده می‌شود و کارکرد مدل کاملاً دست‌نخورده می‌ماند.

## مدل چطور ساخته شد؟

چون این صفحه باید کاملاً سمت مرورگر و بدون پایتون اجرا شود، مراحل زیر یک‌بار و پیش از تحویل پروژه، آفلاین انجام شد:

1. **تولید داده‌ی مصنوعی:** چون به‌خاطر محدودیت اجرای آفلاین امکان دانلود دیتاست واقعی MNIST نبود، حدود ۴۱ هزار تصویر ۲۸×۲۸ از ارقام ۰ تا ۹ به‌صورت مصنوعی ساخته شد؛ بخشی با رندر چند فونت مختلف و بخشی با شبیه‌سازی مستقیمِ ضربه‌قلم (منحنی‌های تصادفی مشابه دست‌خط)، همراه با چرخش، تغییر ضخامت خط، اعوجاج و نویز تصادفی برای تنوع سبک نوشتاری.
2. **آموزش:** یک `MLPClassifier` (از کتابخانه‌ی scikit-learn، دقیقاً همان کلاس نوت‌بوک اصلی) با معماری ۷۸۴ ← ۱۶۰ ← ۸۰ ← ۱۰ و فعال‌سازی ReLU روی این داده آموزش دید.
3. **اعتبارسنجی مستقل:** برای اطمینان از این‌که مدل صرفاً فونت‌ها را حفظ نکرده، روی یک مجموعه‌ی کاملاً جداگانه (تولیدشده با seed و سبک‌های متفاوت) هم آزمایش شد.
4. **صدور وزن‌ها:** وزن‌ها و بایاس‌های هر لایه در قالب JSON استخراج و در `assets/model.js` ذخیره شدند.
5. **اجرای سمت مرورگر:** در `script.js`، یک forward-pass دستی (ضرب ماتریسی + ReLU برای لایه‌های پنهان + Softmax برای خروجی) دقیقاً همان محاسبه‌ای را انجام می‌دهد که scikit-learn زمان پیش‌بینی انجام می‌دهد.

پیش از رسیدن به این مرحله، تصویر رسم‌شده روی بوم هم پردازش می‌شود: پیدا کردن کادر دور رقم، تغییر اندازه به کادر ۲۰×۲۰ داخل بومِ ۲۸×۲۸، و مرکز کردن بر اساس «مرکز جرم» پیکسل‌ها — دقیقاً همان قرارداد پیش‌پردازش استاندارد MNIST..
